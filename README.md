# AI-Powered Digital Style & Wardrobe Assistant

This repository contains the complete monorepo for the AI-Powered Digital Style and Wardrobe Assistant project, including the AI engine, backend APIs, and frontend applications.

## 🏗️ Repository Structure

- `ai-engine/`: Python-based computer vision and recommendation models.
- `backend/`: Server-side logic and database management.
- `frontend/`: Client-side user interface.
- `docs/`: System architecture and API documentation.

## ⚠️ Team Contribution Rules

1. **Never Push Directly to `main`:** All features must be developed on separate branches and merged via Pull Requests.
2. **Code Review:** Every PR requires at least one approval before merging.
3. **Keep it Clean:** Ensure your local environment files (`.env`), datasets, and dependency folders (`node_modules`, `venv`) are strictly ignored by `.gitignore`.
4. **Commit Messages:** Use clear prefixes like `feat:`, `fix:`, or `docs:` (e.g., `feat: add garment classification model`).
